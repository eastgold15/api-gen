# 桶导出（barrel exports）

`barrel` 命令把 `exportIndex` 各组的目录扫成级联 `index.ts`，**Tree Shaking 友好**（子目录不通过 `*` 重新导出整片）。

## 配置来源

`api-config.json` 的 `exportIndex`：

```json
{
  "exportIndex": {
    "includes": [
      "utils",
      "packages/contract/src/utils/constants/definitions"
    ],
    "utils": [],
    "packages/contract/src/utils/constants/definitions": []
  }
}
```

`includes` 列出**组名**。组分两类：

- **约定名组**（`utils` / `hooks` / `helpers` / `constants` / `types` / `schemas` / `validators` / `middleware`）— `sync` 自动扫所有同名目录
- **路径形式组**（组名含 `/` 或以 `.` 开头）— `sync` 把组名当路径递归扫子目录

## 两种组名形式

### 约定名组（utils 等）

`utils` 这种简单名不指定具体路径，`sync` 找所有 `**/utils/` 目录。例如 tradeflow 里：

- `packages/contract/src/utils`（公共合约层工具）
- `apps/b2b-api/src/utils`（后端工具，可选）
- `apps/web/src/utils`（前端工具，可选）

barrel 会对**每个** utils 目录生成 `index.ts`。

### 路径形式组（单目录形式）

`packages/contract/src/utils/constants/definitions` 是 tradeflow 的常量字典目录（`*.def.ts`，含 3 层 DEF + OPTIONS + GROUPS），用路径形式组指向一个具体目录。`sync` 递归展开该目录下**有内容的子目录** + **组根散 .ts 文件**。

## 路径形式组的关键设计

1. **组根只引用一级子目录**：孙级经中间层 barrel 间接暴露。
2. **空数组自动递归展开**：`sync` 看到 `"./x": []` → 扫 `./x` 下所有有内容的子目录 + 散文件填进去。
3. **中间层 barrel re-export 子目录 barrel**：`./x/sub/index.ts` 引用 `./sub-sub`，`./x/index.ts` 引用 `./sub`（不是 `./sub/sub-sub`）。
4. **`!` 排除**：在子项里加 `!./x/sub` 排除该路径，barrel 不引用。

## 例子（constants/definitions）

```
packages/contract/src/utils/constants/definitions/
├── status.def.ts        # 3 层 DEF + OPTIONS + GROUPS
├── order-type.def.ts
└── index.ts             # 由 barrel 生成
```

`index.ts` 内容（自动生成）：

```ts
// Auto-generated by `api-gen barrel` — do not edit manually.
export * from "./order-type.def";
export * from "./status.def";
```

## `--lib` 模式

`barrel --lib` 启用库导出模式：**仅导出 `@public` 标记的符号**。规则：

- 顶层 `index.ts`（package.json `main` 指向的入口）应用 `@public` 过滤。
- 子层 `index.ts`（中间目录）不过滤——子层 barrel 仍全量 re-export，允许 `import { x } from "./folder"` 这种内部用法。
- `@internal` 和未标注的符号在顶层 barrel 排除。
- 类型导出（`export type`）也参与过滤，看符号上方 JSDoc 的 `@public` / `@internal` 标签。

## 手动维护保护

**已存在但首行无 `// Auto-generated by \`api-gen barrel\`` 标记的 `index.ts` 视为手动维护，跳过不覆盖**。要重新生成先删文件，或加 marker 强制覆盖。

## 跑法

```bash
# 全量生成所有组
api-gen barrel

# 单组
api-gen barrel -g utils

# 预览(不写)
api-gen barrel -d

# lib 模式(只导出 @public)
api-gen barrel --lib
```

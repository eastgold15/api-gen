# Barrel Export — 桶导出规范

## 什么是 Barrel Export

Barrel（桶）是 TypeScript 社区对**通过 `index.ts` 集中转发目录内所有导出**的模式称呼。核心思路：

```
utils/pagination/
├── page.ts          ← 叶子文件，写真实代码
└── index.ts         ← barrel，自动转发所有导出
```

## 为什么需要

| 问题 | 方案 |
|------|------|
| 使用者要记深层 import 路径 | 统一从组级 `index.ts` 导入 |
| `export *` 让 Tree Shaker 不敢删 | 全量**具名导出**，精准 tree-shaking |
| 值/类型混在一起，类型无法擦除 | `export {}` / `export type {}` 分离 |
| 手动维护 index 容易漏 | `api-gen barrel` 自动生成 |

## 目录规范

```
contract/
├── utils/
│   ├── pagination/
│   │   ├── page.ts          ← 叶子：真实代码
│   │   └── index.ts         ← barrel：CLI 生成
│   ├── sort/
│   │   ├── sort-helper.ts
│   │   └── index.ts
│   ├── search/
│   │   ├── filter.ts
│   │   └── index.ts
│   └── index.ts             ← 组级 barrel：CLI 生成
├── drizzle/
│   └── index.ts
├── typebox/
│   └── index.ts
├── constants/
│   └── index.ts
└── query-types.model.ts      ← 手动维护
```

## 使用流程

### 1. 配置

在 `.vscode/api-gen.json` 中添加 `exportIndex`：

```json
{
  "exportIndex": {
    "groups": [
      {
        "name": "utils",
        "rootDir": "packages/contract/src/utils"
      }
    ]
  }
}
```

每个 `group` 代表一个导出组：
- `name` — 组名，用于 `--group` 筛选
- `rootDir` — 目录路径（相对项目根）

后续增加 drizzle / typebox / constants 只需加一项：

```json
{
  "exportIndex": {
    "groups": [
      { "name": "utils",     "rootDir": "packages/contract/src/utils" },
      { "name": "drizzle",   "rootDir": "packages/contract/src/drizzle" },
      { "name": "typebox",   "rootDir": "packages/contract/src/typebox" },
      { "name": "constants", "rootDir": "packages/contract/src/constants" }
    ]
  }
}
```

### 2. 运行

```bash
# 扫描所有组，生成 barrel
api-gen barrel

# 只处理某个组
api-gen barrel --group utils

# 预览模式，不写入文件
api-gen barrel --dry-run
```

### 3. 工作流

1. 在 `pagination/page.ts` 中新增/删除/修改导出
2. 运行 `api-gen barrel`
3. CLI 自动更新：
   - `utils/pagination/index.ts`（子模块 barrel）
   - `utils/index.ts`（组级 barrel）
4. 提交变更

## 生成规则

### 子模块 index（如 `utils/pagination/index.ts`）

```
扫描 pagination/ 下的 .ts 文件（跳过 index.ts / *.d.ts / *.test.ts）
  → OXc 提取每个文件的 export 定义
  → 拆分值导出 / 类型导出
  → 生成 per-file import + consolidated export
```

输出示例：

```ts
// Auto-generated by `api-gen barrel` — do not edit manually.

import { calcPage, buildPaginationQuery } from "./page";
import type { PageOpt, PaginationInput } from "./page";

export { calcPage, buildPaginationQuery };
export type { PageOpt, PaginationInput };
```

### 组级 index（如 `utils/index.ts`）

```
扫描 utils/ 下的一级子目录（pagination / sort / search）
  → 读取各子目录 index.ts 的导出集合
  → 汇总所有值/类型导出，按子目录分组 import
```

输出示例：

```ts
// Auto-generated by `api-gen barrel` — do not edit manually.

import { calcPage, buildPaginationQuery } from "./pagination";
import type { PageOpt, PaginationInput } from "./pagination";

export { calcPage, buildPaginationQuery, sortBuilder, createSearchFilter };
export type { PageOpt, PaginationInput, SortRule, SearchCondition };
```

## 安全机制

| 场景 | 行为 |
|------|------|
| `index.ts` 不存在 | 创建 |
| `index.ts` 存在且带自动标记 | 覆盖 |
| `index.ts` 存在但无标记 | **跳过**，warn 提示 |
| 新内容与旧内容相同 | 不写入 |
| `--dry-run` | 预览不落盘 |

## 叶子文件编写规范

```ts
// page.ts  ← 叶子文件

// 函数用 export function
export function calcPage(page: number, limit: number) { ... }

// 常量用 export const
export const DEFAULT_PAGE = 1;

// 类型用 export type
export type PageOpt = { page?: number; limit?: number; };

// 接口用 export interface
export interface PaginationParams { page?: number; limit?: number; }

// ❌ 禁止
export default calcPage;
export * from "./helpers";
```

## 叶子文件导出检测规则（AST 级别）

| 源码 | 导出类型 |
|------|---------|
| `export function xxx` | value |
| `export const xxx = ...` | value |
| `export class Xxx` | value |
| `export enum Xxx` | value |
| `export type Xxx = ...` | type |
| `export interface Xxx` | type |
| `export { a, b }` | value |
| `export type { C, D }` | type |

## TSConfig 推荐配置

```json
{
  "compilerOptions": {
    "module": "ESNext",
    "moduleResolution": "Bundler",
    "verbatimModuleSyntax": true,
    "importsNotUsedAsValues": "remove",
    "isolatedModules": true
  }
}
```

## 禁止清单

1. ❌ `export * from "xxx"` — 必须具名导出
2. ❌ `export default` — 必须是具名导出
3. ❌ index 文件内写可执行代码、副作用
4. ❌ 手动修改 CLI 生成的 index 文件
5. ❌ 同时导出 `./utils` 和 `./utils/index`
6. ❌ 把函数聚合为对象再导出

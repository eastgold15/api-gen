# gen-hook

从 b2b-api 的 controller 路由派生 `web` / `b2b-admin` 的 `src/hooks/api/use-<domain>.ts` Eden-TanStack-Query React hook 骨架。

## 流程

1. 读 `.vscode/api-gen.json`：
   - 找 `appType === "b2b-api"` 的 app 作为 **hook 源**。
   - 找 `appType === "web"` 和 `appType === "b2b-admin"` 的 app 作为 **hook 目标**。
2. 用 [`src/scanner/controller.ts`](../src/scanner/controller.ts) 的 `scanAllControllers` 扫源 app 的 modules，提取每个 controller 的路由列表。
3. 对每个 controller → 一个 `use-<domain>.ts` 文件，target 默认两个（web + b2b-admin 都生成）。

## 命名规则

| 路由形态 | hook 名 | 行为 |
|---------|--------|------|
| `.get("/")` | `useList<Domain>` | `useQuery(eden...get.queryOptions({}))` |
| `.get("/current")` | `useCurrent<Domain>` | `useQuery(eden...current.get.queryOptions({}))` |
| `.get("/:id")` | `use<Domain>Detail(id)` | `useQuery(eden...post.post...get.queryOptions({ id }))`（自动 `(id)` 调用） |
| `.get("/static/path")` | `use<Domain><StaticPathPascal>` | 一般查询 |
| `.post("/")` | `useCreate<Domain>` | `useMutation` + `qc.invalidateQueries` |
| `.post("/<sub>")` | `useCreate<Domain><Sub>` | mutation |
| `.put("/:id")` / `.patch("/:id")` | `useUpdate<Domain>` | mutation |
| `.delete("/:id")` | `useDelete<Domain>` | mutation |

## 输出示例

```ts
// Auto-generated by api-gen gen-hook — do not edit manually.

import { useQuery, useMutation, useQueryClient } from "@tanstack/react-query";
import { useEden } from "@/lib/rpc";
import { toast } from "sonner";

export function useCurrentSite() {
  const eden = useEden();
  return useQuery(
    eden.api.v1.site.current.get.queryOptions(
      {},
      { staleTime: 5 * 60 * 1000 }
    )
  );
}

export function useSiteDetail(id: string) {
  const eden = useEden();
  return useQuery(
    eden.api.v1.site.(id).get.queryOptions(
      { id },
      { staleTime: 5 * 60 * 1000 }
    )
  );
}

export function useCreateSite() {
  const eden = useEden();
  const qc = useQueryClient();
  return useMutation({
    ...eden.api.v1.site.post.mutationOptions(),
    onSuccess: () => {
      toast.success("操作成功");
      qc.invalidateQueries({ queryKey: eden.api.v1.site.get.queryKey() });
    },
    onError: (e: any) => toast.error(e?.value?.title ?? "操作失败"),
  });
}
```

## 参数

| 参数 | 缩写 | 说明 |
|------|------|------|
| `--domain` | `-d` | 限制单 domain（用 controller 变量名转 kebab：`customerController` → `customer`） |
| `--target` | `-t` | `web` / `b2b-admin`，只写单一目标（缺省 = 两个都生成） |

## 保护机制

- **已存在无 marker**：跳过（视为手动维护，warn）。
- **已存在有 marker**：无条件覆盖（hook 骨架完全派生，重复跑不会丢业务修改——因为业务代码本来就不该改 hook 文件）。

## invalidateQueries 启发式

mutation 的 `onSuccess` 里 `qc.invalidateQueries({ queryKey: eden.api.v1.<domain>.get.queryKey() })`——只 invalidate 该 domain 根 `get` 列表，不 invalidate detail（`<domain>.(id).get`）。如果业务需要 invalidate detail，手动加一行。
